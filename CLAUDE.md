# Repo rules

## Commit and push after every change

Commit each finished change and push it to `origin` right away, without waiting to be asked (the
global rule in `~/.claude/CLAUDE.md`).

The repo is public, so before pushing check that the new commits contain no `.env` values and no
git-ignored state files (`social-calendar/state.json`, `social-calendar/kokandus.json`).
